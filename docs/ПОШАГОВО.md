# Пошагово, с нуля (Windows)

Ниже — путь от чистого компьютера до Су-34 в игре. Первые три шага делаются
один раз и занимают вечер (в основном из-за скачивания Unity). Дальше сборка
мода — это две команды.

> Всё, что связано с Unity и Windows, нужно делать на своём ПК. В песочнице,
> где готовился репозиторий, нет ни Windows, ни Unity, ни файлов игры, поэтому
> DLL и asset bundle собираются у вас.

---

## Шаг 0. Что установить

| Что | Где | Зачем |
|---|---|---|
| VTOL VR | Steam | игра |
| VTOL VR Mod Loader | Steam, app **3018410** | загрузчик модов; ставить на тот же диск, что игру |
| .NET SDK 8 | dotnet.microsoft.com | собрать `Su34Mod.dll` |
| Unity Hub + Unity **2020.3.48f1/49f1** | unity.com | собрать asset bundle |
| AssetRipper | github.com/AssetRipper/AssetRipper/releases | развернуть игру в Unity-проект |
| Git (по желанию) | git-scm.com | обновлять репозиторий |

Ещё подпишитесь в Workshop модлоадера на **VTOLAPI** — без него внешние
самолёты получают кривые шейдеры.

---

## Шаг 1. Проверить версию Unity

1. Запустите VTOL VR хотя бы раз.
2. Откройте
   `%USERPROFILE%\AppData\LocalLow\Boundless Dynamics, LLC\VTOLVR\Player.log`
   (или `...\steamapps\common\VTOL VR\Player.log`).
3. Третья строка: `Initialize engine version: 2020.3.xx`. Запомните номер —
   Unity Hub должен поставить **ровно эту** версию (любой патч 2020.3.x
   подойдёт, но лучше точный).

---

## Шаг 2. Развернуть игру в Unity-проект (один раз)

1. Запустите `AssetRipper.GUI.Free.exe`.
2. Перетащите в него папку `...\steamapps\common\VTOL VR`.
3. Дождитесь окончания загрузки, затем `Export > Export All Files` в пустую
   папку, например `D:\VTOLVR_Project`.
4. После экспорта:
   * удалите `AuxiliaryFiles`;
   * содержимое `ExportedProject` перенесите в `D:\VTOLVR_Project`;
   * удалите `Assets\Plugins` целиком (там DLL движка и SteamVR, Unity на них
     падает) — **кроме** того, что положите сами на шаге 4;
   * удалите шейдер `Hidden_UIElements_EditorUIE`.
5. Скопируйте папку `unity\Assets\Su34` из этого репозитория в
   `D:\VTOLVR_Project\Assets\Su34`.
6. Скопируйте `assets\model\su34.obj` и `su34.mtl` в
   `D:\VTOLVR_Project\Assets\Su34\Models\` (папку создайте).
7. Откройте проект в Unity Hub. Первый импорт — 10–40 минут, это нормально.
   Если предлагает «Enter Safe Mode» — выберите **Ignore**.
8. Package Manager → установите `TextMeshPro` (на вопрос — «No Thanks»),
   `XR Plugin Management`, `2D Sprite`, `Input System`.
9. Из SteamVR Plugin (Asset Store) импортируйте плагин, **сняв** галочку с
   `SteamVR > Input > Plugins > JSON.NET > Valve.Newtonsoft.Json.dll`.
10. Создайте `Assets\Plugins` заново и положите туда из
    `VTOL VR\VTOLVR_Data\Managed\`:
    `Assembly-CSharp.dll`, `Assembly-CSharp-firstpass.dll`,
    `Facepunch.Steamworks.Win64.dll`, `Unity.TextMeshPro.dll`;
    из `VTOL VR\@Mod Loader\Managed\`: `0Harmony.dll`,
    `ModLoader.Framework.dll`.
11. `Assets > Reimport All`. Ошибок быть не должно (предупреждения — можно
    игнорировать).

## Шаг 3. Собрать asset bundle

1. В Unity: меню **VTOL VR → Su-34 → 0 - Check setup**. Если пишет, что не
   найден префаб F/A-26B — откройте `Assets` и поищите `FA-26B.prefab`
   (обычно `Assets/Resources/vehicles/FA-26B.prefab`), поправьте путь в
   `Assets/Su34/Editor/Su34BundleBuilder.cs` в константе `DonorPrefabPath`.
2. **1 - Dump donor hierarchy** — создаст `Su34_donor_hierarchy.txt` со всеми
   объектами донора. Полезно, если хочется точно настроить, что скрывать.
3. **2 - Build prefab + asset bundle**. В конце в консоли будет
   `[Su-34] DONE`. В папке репозитория `mod\` появятся `su34` и
   `build_report.txt`.

---

## Шаг 4. Собрать DLL мода и поставить в игру

Из корня репозитория в PowerShell:

```powershell
.\tools\build.ps1                 # соберёт Su34Mod.dll в mod\
.\tools\install.ps1               # скопирует mod\* в игру
```

Если игра стоит не в стандартном месте:

```powershell
.\tools\build.ps1   -GamePath "D:\Steam\steamapps\common\VTOL VR"
.\tools\install.ps1 -GamePath "D:\Steam\steamapps\common\VTOL VR"
```

Можно и вручную: папку `mod` переименовать в `Su-34` и положить в
`...\steamapps\common\VTOL VR\@Mod Loader\Mods\`.

---

## Шаг 5. Запуск

1. Запустите **VTOL VR Mod Loader** из Steam.
2. Включите `VTOLAPI` и `Su-34 Fullback`, нажмите Play.
3. В игре: выбор пилота → список самолётов → **Su-34**.
4. Если что-то не так — `F10` в полёте и лог игры (см. ниже).

---

## Если не работает

| Симптом | Что смотреть |
|---|---|
| Самолёта нет в списке | В логе `[Su-34] asset bundle not found` → в папке мода нет файла `su34`; `[Su-34] the game did not register` → бандл собран без `ExternalVehicleInfo`/неверное имя префаба |
| Самолёт есть, но невидимый | Бандл собран из чужой версии Unity; пересоберите в 2020.3.x, как в шаге 1 |
| Не видно кабины / всё серое | Не установлен VTOLAPI, либо шейдеры донора не прошли `FixShaders` |
| Мод не загружается, в логе `patch '...' could not be applied` | Игра обновилась и переименовала метод — это одна фича, остальное работает; напишите issue с номером версии игры |
| Игра падает при загрузке бандла | Проверьте, что модель не содержит скриптов и что бандл собран под `StandaloneWindows64` |

Лог игры: `%USERPROFILE%\AppData\LocalLow\Boundless Dynamics, LLC\VTOLVR\Player.log`
(ищите строки с `[Su-34]`).
