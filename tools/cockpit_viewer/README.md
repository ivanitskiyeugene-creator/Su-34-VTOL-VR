# Предпросмотр кабины Су-34

Интерактивный просмотр кабины в браузере: те же координаты кресел, что и в
билдере, поэтому видно, куда именно сядет пилот и штурман, что попадает в поле
зрения и не упирается ли голова в фонарь.

## Запуск

```bash
python tools/cockpit_viewer/serve.py        # http://localhost:8000
```

Открыть `http://localhost:8000/` — сервер сам перебросит на просмотрщик.
Порт можно задать аргументом: `python tools/cockpit_viewer/serve.py 8123`.

Сервер отдаёт корень репозитория, потому что просмотрщику нужны
`assets/model/su34_donor.obj` и текстуры рядом с ним. Ничего не собирает и
никуда не пишет.

## Что можно делать

| Действие | Как |
|---|---|
| Вращать | левая кнопка мыши |
| Двигаться | правая кнопка или Shift + мышь |
| Приблизить | колесо |
| Точки обзора | кнопки слева или клавиши `1`–`6` |

Слева — точки обзора (пилот, штурман, приборная панель, взгляд вправо, оба
кресла, внешний вид) и ползунки «высота глаз» и «вперёд/назад»: так видно,
при каком росте игрока голова перестаёт упираться в фонарь.

Справа — что показывать: корпус, интерьер кабины, стекло фонаря, маркеры
кресел, шасси (по умолчанию выключено, чтобы не мешало смотреть). Там же
ползунки прозрачности фонаря и корпуса — с прозрачным корпусом видно, как
кресла соотносятся с обводами самолёта.

Маркеры: синий крест — левое кресло (пилот), красный — правое (штурман),
подпись «глаза» — точка, с которой снимаются статические ракурсы.

## Числа

Берутся из тех же измерений по мешу, что и в `Su34BundleBuilder.cs`:

* чаша левого кресла — x −0.71…−0.34, правого — +0.34…+0.71;
* верх подушки — y 1.52;
* центр кресла по оси — z 6.30;
* глаза — y 2.22, z 6.22: на этой высоте стоит остекление HUD
  (y 2.11…2.35), то есть пилот смотрит сквозь него, а не под него.

Статические картинки из тех же ракурсов лежат в `docs/model/cockpit_*.png`,
их печатает `tools/render_cockpit.py`.
